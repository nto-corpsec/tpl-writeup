# tpl-writeup

Шаблон разбора задачи: воспроизводимый ход решения, доказательства, выводы.

> **Важно.** Ответы и флаги в публичный writeup не попадают. Разбор публикуется после
> этапа (после 15.12) или в приватном `ops`, если нужен команде раньше.

## Структура

```
TEMPLATE.md          # скелет разбора
writeups/<task-id>.md
```

## Как писать

1. Копируй `TEMPLATE.md` в `writeups/<task-id>.md`.
2. Пиши так, чтобы другой человек воспроизвёл решение с нуля.
3. Каждый вывод — со ссылкой на артефакт и хешем.
4. Не вставляй уникальные строки из условия задания: они позволяют найти ответ.

## Проверки

- markdownlint (структура и стиль)
- lychee (битые локальные ссылки)
- no-leak (флаги и ключи)
